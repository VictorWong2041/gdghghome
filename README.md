# 广智新工作台 UI 还原

直接打开 `index.html` 即可使用，无需安装依赖或联网。请保留同目录下的 `styles.css`、`app.js` 和 `assets` 文件夹。

也可以在本目录运行 `python3 -m http.server 8080`，浏览器访问 http://localhost:8080。

支持待办分类与办理、邮件阅读与回复草稿、全局搜索、日历翻月与日期选择、新建日程、常用功能面板、申请表单、打卡、AI演示对话等交互。办理记录、已读邮件、新建日程和打卡状态保存在当前浏览器 localStorage 中。

这是前端交互原型，未连接企业后台、邮件发送服务或真实 AI 接口。原图中的2025年11月日历及示例文案予以保留；待办中前三项为待处理，第四项为信息事项，因此初始计数为3。

原图基准为3840×2160，布局按2048×1152的逻辑尺寸还原，并适配较小屏幕。装饰插画与头像从用户提供的原图中提取，其他页面元素使用 HTML、CSS 和 SVG 实现。

页面以2048×1152为基准，按浏览器可用宽高等比例缩放，包括窄侧栏预览，保持所有模块在一屏内完整呈现。

## AI 工作台

点击右侧 AI 按钮切换到 AI 工作台，点击“常用”返回原工作台。新增的 `ai-workspace.css`、`ai-workspace.js` 及 `assets/ai-*.png` 需要与入口文件一起保留。

AI 工作台支持能力卡片选择、热门/最近/常用问题切换、输入消息、新建会话、恢复本地历史、选择附件、搜索模式和模型选择。Enter 发送，Shift+Enter 换行。历史保存在浏览器本地，消息回复为已标注的预设示例，附件不会上传，联网、语音和真实模型调用尚未接入。

## 浮动切换按钮

“常用 / AI”按钮组独立于页面缩放，默认在浏览器可视区域垂直居中，距右边缘32 CSS像素。按住任意位置拖动可调整位置，拖动不会触发页面切换，位置自动保存在当前浏览器。拖动及窗口缩放时保持在可视区域内；双击按钮组空白处可恢复默认位置。

## 页面宽度与顶部菜单

画布根据窗口宽高扩展，组件维持等比例缩放，消除宽屏下左右额外的画布留白。AI 侧栏贴合页面左缘，顶部控件贴合右侧内边距，中央内容保持居中。

顶部搜索、设置、帮助图标使用线性 SVG。设置按钮展开“差旅偏好 / 自定义工作台 / 设置 / 退出系统”；帮助按钮展开“反馈 / 帮助”。菜单默认收起，支持互斥展开、外部点击关闭、Esc 收起及方向键导航。差旅偏好与默认工作台可本地保存，退出系统入口提示尚未接入统一登录服务。
