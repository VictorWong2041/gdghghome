# 广智新工作台 UI 还原

直接打开 `index.html` 即可使用，无需安装依赖或联网。请保留同目录下的 `styles.css`、`app.js` 和 `assets` 文件夹。

也可以在本目录运行 `python3 -m http.server 8080`，浏览器访问 http://localhost:8080。

支持待办分类与办理、邮件阅读与回复草稿、全局搜索、日历翻月与日期选择、新建日程、常用功能面板、申请表单、打卡、AI演示对话等交互。办理记录、已读邮件、新建日程和打卡状态保存在当前浏览器 localStorage 中。

这是前端交互原型，未连接企业后台、邮件发送服务或真实 AI 接口。原图中的2025年11月日历及示例文案予以保留；待办中前三项为待处理，第四项为信息事项，因此初始计数为3。

原图基准为3840×2160，布局按2048×1152的逻辑尺寸还原，并适配较小屏幕。装饰插画与头像从用户提供的原图中提取，其他页面元素使用 HTML、CSS 和 SVG 实现。

页面以2048×1152为基准，按浏览器可用宽高等比例缩放，包括窄侧栏预览，保持所有模块在一屏内完整呈现。

## AI 工作台

点击右侧 AI 按钮切换到 AI 工作台，点击“常用”返回原工作台。新增的 `ai-workspace.css`、`ai-workspace.js` 及 `assets/ai-*.png` 需要与入口文件一起保留。

AI 工作台支持能力卡片选择、热门/最近/常用问题切换、输入消息、新建会话、恢复本地历史、选择附件、搜索模式和模型选择。Enter 发送，Shift+Enter 换行。历史保存在浏览器本地，消息回复为已标注的预设示例，附件不会上传，联网、语音和真实模型调用尚未接入。

## 浮动切换按钮

“常用 / AI”按钮组独立于页面缩放，默认在浏览器可视区域垂直居中，距右边缘32 CSS像素。按住任意位置拖动可调整位置，拖动不会触发页面切换，位置自动保存在当前浏览器。拖动及窗口缩放时保持在可视区域内；双击按钮组空白处可恢复默认位置。

## 页面宽度与顶部菜单

画布根据窗口宽高扩展，组件维持等比例缩放，消除宽屏下左右额外的画布留白。AI 侧栏贴合页面左缘，顶部控件贴合右侧内边距，中央内容保持居中。

顶部搜索、设置、帮助图标使用线性 SVG。设置按钮展开“差旅偏好 / 自定义工作台 / 设置 / 退出系统”；帮助按钮展开“反馈 / 帮助”。菜单默认收起，支持互斥展开、外部点击关闭、Esc 收起及方向键导航。差旅偏好可本地保存，自定义工作台进入布局编辑器，退出系统入口提示尚未接入统一登录服务。

## 广新门户与数据看板

点击顶部“广新门户”进入资讯页面，右侧浮动按钮切换“资讯 / 数据”；点击顶部“工作台”返回常用工作台，保留 AI 入口。

- 资讯页面支持新闻分类、关键词搜索、卡片横向翻页、宣传轮播、提醒查看/忽略、通知公告详情。
- 新闻卡片链接到广新集团官网的实际详情页，在新标签页打开。9条新闻标题、日期及HTTP状态已核验，记录见 `output/playwright/news-links.json`。卡片插图与横幅沿用用户提供的设计稿；横幅内容为设计示意，不作为实时排名信息。
- 数据看板使用设计稿示例数值，未接入真实经营财务数据。支持财务范围切换、纳税企业/年度选择、项目条件筛选、项目详情、图表悬浮提示、省份税金详情及地图缩放。
- “政策法规”和“党建”分类在当前样例集中暂无已核实条目，显示空状态。通知公告和主动提醒为设计稿演示内容。
- 页面使用纯 HTML/CSS/JS/SVG，无额外运行依赖；新增 `portal.css`、`portal-news.js`、`portal.js` 及对应 `assets` 素材需一起保留。官网新闻跳转需要网络。

## IM 与通讯录

顶部 IM 默认显示“欢迎使用广智新 IM”，不预选会话。选择左侧联系人或群组后显示聊天内容，只有点击右上角“…”才展开详情；再次点击或按 Esc 关闭。支持本地文字/表情消息、新建群聊、搜索聊天记录、成员检索、置顶与免打扰。附件仅记录文件名，不上传；语音、二维码邀请等尚未连接真实服务。

右侧“通讯录”默认选中“组织架构”，支持组织/部门下钻、搜索、联系人资料、最近联系人和我的群组。组织人数和会话内容均来自设计稿样例，消息只保存在浏览器本地。

## 资讯卡片横向浏览

AI 智能资讯和集团综合资讯根据实际溢出显示左右箭头：起点隐藏向左，到终点隐藏向右，内容不足一屏时两侧均隐藏。两个组件都支持按住鼠标左右拖动，适配页面缩放；拖动结束不会触发新闻链接，普通点击仍在新窗口打开对应官网新闻。


## 所见即所得工作台编辑

通过“设置 → 自定义工作台”进入真实布局编辑页。编辑与普通工作台复用同一批组件和背景，不使用替代截图。

- 按住组件标题、内容、列表、图片或空白区域均可拖动；拖到尺寸合适的另一组件上交换布局，空白区域可自由定位。
- 右下角手柄缩放，也可选中组件后输入宽、高；关闭按钮隐藏组件，可从组件库恢复。
- 组件库共11种组件，支持拖入或点击添加；画布空间不足时自动整理，避免组件互相遮挡。
- 常用功能、系统导航内的快捷入口使用 **Alt＋拖动** 排序，普通拖动移动整个组件。
- 支持撤销、重置、放弃修改返回及保存并生效。保存的位置、大小、显示状态和快捷入口顺序存于本地，刷新后保留。
- 编辑后离开工作台时仍保证各主页面互斥显示，防止门户与工作台重叠。

## Banner 与字体更新

门户 Banner 显示两张实图，底部标题为16px Regular，使用较浅的渐变遮罩；右上角轮播指示器无底层。每8秒自动切换，手动切换后重新计时，离开页面或浏览器隐藏时暂停。第二张使用用户提供的佛塑科技照片，并链接到对应官网新闻。超长标题单行省略，悬停可查看完整标题。

IM 采用正文14/22px、辅助说明12/18px、模块标题16/24px的字号/行高，标题Medium、正文Regular。右上角使用紧凑的三圆点SVG，发送按钮96×40px，工具栏按钮36×36px。

“集团邮箱”已更名为“邮箱服务”，默认三条邮件：两封未读、一封已读。首次应用新默认状态后，后续阅读状态正常保存，不会在每次刷新时重新设为未读。
